# Smartphone Retailing Sales Dashboard | Power BI

## Project Overview

This project focuses on analyzing smartphone retail sales using Microsoft Power BI. The dashboard provides insights into sales performance, customer purchasing behavior, payment preferences, and product performance.

The objective is to transform raw sales data into meaningful insights through interactive visualizations and KPI indicators.

## Key Performance Indicators (KPIs)

- **Total Sales:** 5M
- **Total Quantity:** 114
- **Total Transactions:** 23
- **Average:** 41K (as displayed in the dashboard)

## Key Analysis

### 1. Sales by Mobile Model
Analyzes sales performance across different smartphone models, including Galaxy A51, Galaxy S21, and Galaxy Note 20.

### 2. Sales by Payment Method
Examines the distribution of sales across Debit Card, Credit Card, UPI, and Cash.

### 3. Quantity by Customer Ratings
Analyzes the quantity of products associated with different customer ratings.

### 4. Monthly Sales Analysis
Identifies monthly sales trends and highlights variations in sales performance throughout the year.

### 5. Sales by Day
Compares sales performance across different days of the week.
